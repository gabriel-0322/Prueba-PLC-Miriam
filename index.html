Álgebra Booleana y Ecuaciones del Sistema

1. Permisivo EPP (Cofia y Cubrebocas)
M_{EPP} = I_{0.4} · I_{0.5}
Exige simultáneamente cofia reglamentaria y mascarilla facial hermética.
2. Inicio de Secuencia (Set M0.0)
S_{M0.0} = I_{0.0} · I_{0.1} · M_{EPP} · \overline{I_{0.2}} · \overline{I_{0.3}} · \overline{M_{0.5}}
Arranque permisivo sólo si el operario porta EPP completo y coloca manos.
3. Cascada de Salidas Secuenciales
Q_{0.0} = M_{0.0} · \overline{T_{1}.Q} \quad ( ext{Jabón 3s})
Q_{0.5} = M_{0.0} · T_{1}.Q · \overline{T_{2}.Q} \quad ( ext{Frotado 20s})
Q_{0.1} = M_{0.0} · T_{2}.Q · \overline{T_{3}.Q} \quad ( ext{Agua 10s})
Q_{0.2} = M_{0.0} · T_{3}.Q · \overline{T_{4}.Q} \quad ( ext{Spray 3s})
4. Permisivo Final de Apertura (Q0.3)
Q_{0.3} = M_{0.5} · M_{EPP} · \overline{T_{5}.Q}
Desbloqueo de puerta por 10s: Exige lavado terminado (M0.5) Y confirmación de EPP presente.
5. Interbloqueo de Abandono o Violación EPP
R_{Total} = (M_{0.0} · \overline{M_{0.5}} · \overline{I_{0.1}}) + (M_{0.0} · \overline{M_{EPP}}) + I_{0.2} + I_{0.3}
Si retira manos o se quita la mascarilla/cofia, resetea a cero y bloquea la puerta.

1. Contextualización Sectorial: Salas de Operaciones e Industria Alimentaria

En entornos clínicos de alta criticidad, como las Salas de Operaciones (Quirófanos Clase ISO 5 a ISO 7 bajo UNE 100713), las Infecciones del Sitio Quirúrgico (ISQ) y las Infecciones Asociadas a la Atención en Salud (IAAS) representan una de las principales causas de morbimortalidad postoperatoria y sobrecostos hospitalarios. De forma análoga, en la Industria Alimentaria de Alto Riesgo regida por HACCP, ISO 22000, FSSC 22000 y BPM, la introducción inadvertida de patógenos o cuerpos extraños puede originar brotes de toxiinfecciones alimentarias masivas y costosos retiros de producto del mercado.

El vector de contaminación más frecuente es el ser humano, a través de tres vías críticas:

  • Desprendimiento Capilar y Dérmico: Un ser humano desprende naturalmente entre 50 y 100 cabellos diarios y millones de escamas de piel cargadas de Staphylococcus aureus meticilino-resistente (MRSA) y Staphylococcus epidermidis. La cofia quirúrgica retiene mecánicamente estas partículas.
  • Emisión de Microgotas Respiratorias: Al hablar, respirar o toser, se generan aerosoles cargados de flora nasofaríngea y virus. El cubrebocas / mascarilla de grado quirúrgico ejerce una barrera de filtración bacteriana (BFE ≥ 98%).
  • Manos como Fómites Vivos: La flora transitoria cutánea transporta enterobacterias (Salmonella, E. coli) o gérmenes intrahospitalarios. El protocolo de 46 segundos (Jabón 3s → Frotado 20s → Enjuague 10s → Spray 3s) desestructura la bicapa lipídica de bacterias y virus según directrices de la OMS.

Inspirado en las esclusas de acceso hermético de plantas de vanguardia en Japón (protocolos Kaizen/Chubo), Corea del Sur (estándares sanitarios MFDS) y China (normativa nacional de inocuidad GB 14881), este sistema transforma el acceso peatonal en una barrera inviolable gobernada por lógica determinística.

2. Justificación de la Automatización con PLC frente a la Supervisión Humana

Históricamente, el control de acceso higiénico ha dependido de la supervisión visual mediante guardias o de la disciplina individual del personal. La ingeniería de factores humanos demuestra que este modelo fracasa por:

  • Fatiga Cognitiva y Complacencia: En turnos hospitalarios o plantas procesadoras de 8 a 12 horas, los supervisores humanos disminuyen su agudeza perceptiva, tolerando personal con cubrebocas por debajo de la nariz o lavados de manos superficiales de menos de 5 segundos.
  • Presión de Tiempo y Sesgos Subjetivos: El personal con prisa suele omitir etapas del lavado. Un supervisor humano puede ceder ante jerarquías o prisas de cirujanos o supervisores de planta.
  • Falta de Registro Inalterable: La supervisión manual no genera trazas digitales de auditoría en tiempo real.

Ventajas del Controlador Lógico Programable (PLC):

  • Determinismo Temporal Inquebrantable: El PLC escanea su lógica cada 50 ms. Los 20 segundos de frotado no admiten atajos; si faltan 100 ms, la compuerta no se desbloquea.
  • Trazabilidad y Auditoría Continua: El bloque contador CTU C1 registra con precisión matemática el número de operarios que han cumplido el protocolo al 100%.
  • Ergonomía Touchless (Cero Fómites): Todo el accionamiento se efectúa por barreras ópticas y sensores infrarrojos. El operario nunca toca manijas ni llaves metálicas donde pudiera ocurrir recontaminación.

4. Alcance Técnico del Proyecto y Límites Operativos

Alcance del Sistema Automatizado:

  • Control discreto determinístico mediante autómata programable bajo estándar IEC 61131-3.
  • Enclavamiento de seguridad biológica bidireccional: nadie accede sin EPP completo Y sin lavado concluido.
  • Protección anti-tamper en tiempo real: aborto instantáneo a 0 segundos si el usuario retira las manos o se despoja de la cofia/mascarilla antes de tiempo.
  • Señalización semafórica normalizada ISA-101 (Rojo = Bloqueado, Amarillo = Frotado en curso, Verde = Acceso libre).
  • Auditoría automatizada mediante registro inalterable en el contador CTU C1.

Límites Operativos:

  • Topología Unidireccional: Diseñado como esclusa de entrada hacia zona limpia (la salida suele realizarse por compuerta de escape libre con barra antipánico).
  • Lógica Discreta 24V DC: Toda la lógica es booleana on/off; las cámaras de visión artificial entregan una salida a relé/transistor limpia hacia las entradas digitales del PLC.
  • Alcance Sanitario: En quirófanos, esta compuerta asegura la preparación aséptica inicial y el porte de EPP para el ingreso a la sala de operaciones. El lavado quirúrgico profundo de cirujanos (con cepillo y clorhexidina en antebrazos) se complementa en áreas anexas sin alterar el control de acceso del recinto.

Manual de Demostración en Aula: Evaluación de los 4 Modos

Para exponer la aplicación ante un comité docente o industrial, ejecute la siguiente secuencia pedagógica utilizando el Selector de Subsistemas:

  1. Demostración de Modo 1: Subsistema de Cofia (`I0.4`):

    Haga clic en el botón superior "Modo 1: Verificación de Cofia". Muestre cómo el escáner superior ilumina la cabeza del avatar. Conmute el botón "Cofia Colocada (I0.4)" a OFF. Observe cómo el haz se torna rojo, se expone el cabello humano en el avatar, se dispara la alarma de bioseguridad capilar y la compuerta bloquea cualquier intento de ingreso.

  2. Demostración de Modo 2: Subsistema de Cubrebocas (`I0.5`):

    Seleccione "Modo 2: Verificación de Cubrebocas". Conmute el botón "Cubrebocas Puesto (I0.5)" a OFF. Muestre cómo el escáner facial indica fallo de mascarilla, la boca/nariz del avatar quedan descubiertas y el display HMI alerta de riesgo respiratorio.

  3. Demostración de Modo 3: Subsistema de Higiene de Manos (5 Etapas):

    Seleccione "Modo 3: Higiene de Manos". Active la velocidad "3x Exposición". Conmute Presencia (`I0.0`) y Manos (`I0.1`). Muestre la animación de gotas de jabón (3s), el frotado enérgico con baliza amarilla (20s), el enjuague de agua (10s) y el spray desinfectante (3s). Demuestre la falla retirando las manos a mitad del frotado: el PLC reinicia el cronómetro a 0 segundos y rebloquea el acceso.

  4. Demostración de Modo 4: Sistema Integrado Completo (Quirófano / HACCP):

    Seleccione "Modo 4: Sistema Integrado Completo" o active el botón "▶ Demo Automática". El sistema validará que tanto la cofia como la mascarilla estén en 1, esperará la finalización exitosa de los 46 segundos de lavado, incrementará el contador `CTU C1` (+1), desbloqueará la cerradura magnética y encenderá la luz verde durante 10 segundos para el paso del operario.

Firmware C / Arduino Actualizado con Lógica EPP

// =========================================================================
// SANITIGATE PLC v3.0 — FIRMWARE DETERMINÍSTICO CON VALIDACIÓN EPP
// =========================================================================
const int PIN_I00 = 2;  // Sensor Presencia
const int PIN_I01 = 3;  // Sensor Manos
const int PIN_I02 = 4;  // Stop Normal
const int PIN_I03 = 5;  // Paro Emergencia
const int PIN_I04 = 6;  // Sensor Cofia (Visión)
const int PIN_I05 = 7;  // Sensor Cubrebocas

const int PIN_Q00 = 8;  // Jabón (3s)
const int PIN_Q01 = 9;  // Agua (10s)
const int PIN_Q02 = 10; // Spray Desinfectante (3s)
const int PIN_Q03 = 11; // Cerradura + Baliza Verde (10s)
const int PIN_Q04 = 12; // Baliza Roja (Bloqueado)
const int PIN_Q05 = 13; // Baliza Amarilla (Frotado 20s)

enum EstadoSanitario { IDLE, JABON, FROTADO, ENJUAGUE, SPRAY, ACCESO };
EstadoSanitario etapaActual = IDLE;

unsigned long tiempoInicioEtapa = 0;
unsigned int contadorPersonal = 0;

void setup() {
  pinMode(PIN_I00, INPUT); pinMode(PIN_I01, INPUT);
  pinMode(PIN_I02, INPUT); pinMode(PIN_I03, INPUT);
  pinMode(PIN_I04, INPUT); pinMode(PIN_I05, INPUT);

  pinMode(PIN_Q00, OUTPUT); pinMode(PIN_Q01, OUTPUT);
  pinMode(PIN_Q02, OUTPUT); pinMode(PIN_Q03, OUTPUT);
  pinMode(PIN_Q04, OUTPUT); pinMode(PIN_Q05, OUTPUT);

  apagarActuadores();
  digitalWrite(PIN_Q04, HIGH); // Puerta bloqueada por defecto
}

void loop() {
  bool pres = digitalRead(PIN_I00);
  bool manos = digitalRead(PIN_I01);
  bool stop = digitalRead(PIN_I02);
  bool emerg = digitalRead(PIN_I03);
  bool cofia = digitalRead(PIN_I04);
  bool cubrebocas = digitalRead(PIN_I05);

  bool eppOK = cofia && cubrebocas;

  // 1. Interbloqueo de Seguridad
  if (emerg || stop) {
    etapaActual = IDLE;
    apagarActuadores();
    digitalWrite(PIN_Q04, HIGH);
    return;
  }

  // 2. Interbloqueo Anti-Violación EPP durante el proceso
  if (etapaActual != IDLE && !eppOK) {
    etapaActual = IDLE; // Aborto inmediato si se quita cofia o mascarilla
    apagarActuadores();
    digitalWrite(PIN_Q04, HIGH);
    return;
  }

  // 3. Interbloqueo Anti-Abandono de Manos
  if (etapaActual != IDLE && etapaActual != ACCESO && !manos) {
    etapaActual = IDLE; // Aborto a 0 segundos
    apagarActuadores();
    digitalWrite(PIN_Q04, HIGH);
    return;
  }

  // 4. Máquina de Estados Finitos (FSM)
  unsigned long ahora = millis();
  unsigned long transcurrido = ahora - tiempoInicioEtapa;

  switch (etapaActual) {
    case IDLE:
      digitalWrite(PIN_Q04, HIGH); // Luz Roja
      if (pres && manos && eppOK) {
        etapaActual = JABON;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q00, HIGH); // Dosificar Jabón
      }
      break;

    case JABON: // 3.0 s
      if (transcurrido >= 3000) {
        digitalWrite(PIN_Q00, LOW);
        etapaActual = FROTADO;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q05, HIGH); // Luz Amarilla Frotado
      }
      break;

    case FROTADO: // 20.0 s
      if (transcurrido >= 20000) {
        digitalWrite(PIN_Q05, LOW);
        etapaActual = ENJUAGUE;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q01, HIGH); // Activar Agua
      }
      break;

    case ENJUAGUE: // 10.0 s
      if (transcurrido >= 10000) {
        digitalWrite(PIN_Q01, LOW);
        etapaActual = SPRAY;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q02, HIGH); // Activar Spray
      }
      break;

    case SPRAY: // 3.0 s
      if (transcurrido >= 3000) {
        digitalWrite(PIN_Q02, LOW);
        // Validación estricta final de EPP antes de abrir
        if (eppOK) {
          digitalWrite(PIN_Q04, LOW);  // Apagar Luz Roja
          digitalWrite(PIN_Q03, HIGH); // Desbloquear Puerta + Luz Verde
          contadorPersonal++;
          etapaActual = ACCESO;
          tiempoInicioEtapa = millis();
        } else {
          etapaActual = IDLE;
        }
      }
      break;

    case ACCESO: // 10.0 s de paso peatonal
      if (transcurrido >= 10000) {
        digitalWrite(PIN_Q03, LOW);  // Rebloquear Puerta
        digitalWrite(PIN_Q04, HIGH); // Luz Roja
        etapaActual = IDLE;
      }
      break;
  }
}

void apagarActuadores() {
  digitalWrite(PIN_Q00, LOW); digitalWrite(PIN_Q01, LOW);
  digitalWrite(PIN_Q02, LOW); digitalWrite(PIN_Q03, LOW);
  digitalWrite(PIN_Q05, LOW);
}
