1. Contexto Empresarial e Inspiración en Plantas de Alimentos de Japón, China y Corea

En las plantas de procesamiento de alimentos de alta inocuidad en Japón (protocolos Kaizen y Chubo), Corea del Sur (estándares MFDS) y China (norma nacional GB 14881), el acceso a las salas de producción limpias está gobernado por esclusas físicas automatizadas. La premisa fundamental de la automatización industrial en inocuidad es: "No confiar el cumplimiento de una norma crítica de bioseguridad al criterio o disciplina variable del operario humano".

La compuerta inteligente SanitiGate PLC resuelve los tres problemas más graves de contaminación cruzada en cocinas industriales, plantas alimentarias y áreas médicas:

  • Omisión de lavado: Operarios con prisa que entran sin lavarse las manos o simplemente mojándose las puntas de los dedos sin jabón.
  • Frotado insuficiente: La OMS y los estándares HACCP/BPM exigen un mínimo de 20 segundos de fricción mecánica con jabón para desestructurar la cápside lipídica de virus y bacterias. El ser humano promedio solo frota entre 5 y 8 segundos.
  • Recontaminación: Uso de grifos manuales o manijas donde las manos limpias vuelven a contaminarse al cerrar la válvula o abrir la puerta.

2. Alcance del Proyecto y Justificación de la Automatización con PLC

El sistema se concibió como un control secuencial 100% digital gobernado por un PLC industrial (o microcontrolador equivalente bajo norma IEC 61131-3), sin requerir sensores analógicos complejos que eleven el costo de mantenimiento.

  • Cero contaminación cruzada: Todo el proceso es touchless mediante barreras fotoeléctricas difusas y sensores ópticos infrarrojos de 24V DC.
  • Interbloqueo Físico Inquebrantable (Anti-Tamper): La cerradura electromagnética de 600 lbs impide mecánicamente el paso hasta que el último milisegundo de atomización de desinfectante haya concluido.
  • Auditoría de Inocuidad Automatizada: El bloque contador CTU C1 registra exclusivamente a aquellas personas que completaron el protocolo de 46 segundos al 100%, facilitando auditorías de BPM y trazabilidad ante autoridades sanitarias.
  • Seguridad de Vida (Life Safety): Interbloqueo con Paro de Emergencia normalizado para desenergizar actuadores en caso de evacuación o siniestro.

3. Arquitectura de Temporización (Ciclo Secuencial de 46 Segundos)

El ciclo total se estructura en 5 etapas secuenciales mutuamente excluyentes, totalizando 46 segundos:

Manual de Demostración y Defensa Académica en Aula

Para defender este proyecto ante un comité evaluador o docente, siga este protocolo de demostración en 3 fases clave:

  1. Demostración de Ciclo Normal Exitoso (Uso del modo 3x):

    Active la velocidad "3x Exposición" en la barra superior. Haga clic en "1. Acercar Persona (I0.0)" y luego en "2. Colocar Manos (I0.1)". Observe cómo el Ladder se energiza en cascada desde Network 1 hasta Network 14, pasando por Jabón (3s) → Luz Amarilla Frotado (20s) → Agua (10s) → Spray Desinfectante (3s). Al llegar a los 36s acumulados, se valida M0.5, el contador CTU C1 suma +1, la cerradura se desbloquea, la baliza verde se enciende y la puerta se abre físicamente durante 10 segundos para el paso del operario.

  2. Demostración de Falla por Retiro Prematuro (Anti-Abandono):

    Inicie un nuevo ciclo. Cuando el simulador se encuentre en la Etapa 2 de Frotado (o en cualquier etapa previa a la puerta), presione el botón rojo "¡Retirar Manos Ahora! (Probar Infracción)". Muestre al docente cómo:

    • El sensor I0.1 cae a cero.
    • Network 17 y 18 se activan inmediatamente en el diagrama Ladder.
    • Todos los temporizadores TON T1..T4 se resetean inmediatamente a 0.0 segundos.
    • La cerradura permanece 100% bloqueada y la baliza roja Q0.4 encendida.
    • El sistema emite una alarma y muestra la alerta de inocuidad en pantalla.
  3. Demostración de Seguridad por Paro de Emergencia:

    Presione el pulsador tipo hongo "PARO DE EMERGENCIA (I0.3)". Compruebe cómo Network 1 desactiva M_RUN, se cancelan todas las salidas y el PLC entra en modo alarma parpadeante hasta desenclavar el pulsador.

1. Esquema de Conexión de Hardware en Proteus

2. Firmware C / Arduino Equivalente (Estructura de Ciclo Determinístico)

Si prefiere programar directamente el microcontrolador en Proteus en lenguaje C o Arduino IDE sin LDmicro, este es el código determinístico equivalente:

// =========================================================================
// SANITIGATE PLC — FIRMWARE PARA ATmega328P / PIC16F877A EN PROTEUS
// Ciclo de escaneo determinístico no bloqueante con millis()
// =========================================================================

const int PIN_I00 = 2;  // Sensor Presencia
const int PIN_I01 = 3;  // Sensor Manos
const int PIN_I02 = 4;  // Stop Normal
const int PIN_I03 = 5;  // Paro Emergencia
const int PIN_I04 = 6;  // Reset Contador

const int PIN_Q00 = 7;  // Jabón (3s)
const int PIN_Q01 = 8;  // Agua (10s)
const int PIN_Q02 = 9;  // Spray Desinfectante (3s)
const int PIN_Q03 = 10; // Cerradura + Luz Verde (10s)
const int PIN_Q04 = 11; // Luz Roja (Bloqueado)
const int PIN_Q05 = 12; // Luz Amarilla (Frotado 20s)

enum EstadoSanitario { IDLE, JABON, FROTADO, ENJUAGUE, SPRAY, ACCESO };
EstadoSanitario etapaActual = IDLE;

unsigned long tiempoInicioEtapa = 0;
unsigned int contadorPersonal = 0;

void setup() {
  pinMode(PIN_I00, INPUT); pinMode(PIN_I01, INPUT);
  pinMode(PIN_I02, INPUT); pinMode(PIN_I03, INPUT); pinMode(PIN_I04, INPUT);
  
  pinMode(PIN_Q00, OUTPUT); pinMode(PIN_Q01, OUTPUT); pinMode(PIN_Q02, OUTPUT);
  pinMode(PIN_Q03, OUTPUT); pinMode(PIN_Q04, OUTPUT); pinMode(PIN_Q05, OUTPUT);
  
  apagarActuadores();
  digitalWrite(PIN_Q04, HIGH); // Luz Roja activa por defecto (Puerta Bloqueada)
}

void loop() {
  bool pres = digitalRead(PIN_I00);
  bool manos = digitalRead(PIN_I01);
  bool stop = digitalRead(PIN_I02);
  bool emerg = digitalRead(PIN_I03);
  bool resetCnt = digitalRead(PIN_I04);

  // 1. Interbloqueo de Seguridad (Emergencia o Stop)
  if (emerg || stop) {
    etapaActual = IDLE;
    apagarActuadores();
    digitalWrite(PIN_Q04, HIGH);
    return;
  }

  // 2. Reset de Contador
  if (resetCnt) contadorPersonal = 0;

  // 3. Protección Anti-Abandono (Manos retiradas antes de tiempo)
  if (etapaActual != IDLE && etapaActual != ACCESO && !manos) {
    etapaActual = IDLE; // Aborto inmediato a cero
    apagarActuadores();
    digitalWrite(PIN_Q04, HIGH);
    return;
  }

  // 4. Máquina de Estados Finitos (FSM) gobernada por TON
  unsigned long ahora = millis();
  unsigned long transcurrido = ahora - tiempoInicioEtapa;

  switch (etapaActual) {
    case IDLE:
      digitalWrite(PIN_Q04, HIGH); // Luz Roja fija
      if (pres && manos) {
        etapaActual = JABON;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q00, HIGH); // Activar Jabón
      }
      break;

    case JABON: // 3.0 segundos
      if (transcurrido >= 3000) {
        digitalWrite(PIN_Q00, LOW);
        etapaActual = FROTADO;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q05, HIGH); // Luz Amarilla Frotado
      }
      break;

    case FROTADO: // 20.0 segundos obligatorios
      if (transcurrido >= 20000) {
        digitalWrite(PIN_Q05, LOW);
        etapaActual = ENJUAGUE;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q01, HIGH); // Activar Agua
      }
      break;

    case ENJUAGUE: // 10.0 segundos
      if (transcurrido >= 10000) {
        digitalWrite(PIN_Q01, LOW);
        etapaActual = SPRAY;
        tiempoInicioEtapa = millis();
        digitalWrite(PIN_Q02, HIGH); // Activar Spray
      }
      break;

    case SPRAY: // 3.0 segundos
      if (transcurrido >= 3000) {
        digitalWrite(PIN_Q02, LOW);
        digitalWrite(PIN_Q04, LOW);  // Apagar Luz Roja
        digitalWrite(PIN_Q03, HIGH); // Desbloquear Cerradura + Luz Verde
        contadorPersonal++;          // CTU C1 +1
        etapaActual = ACCESO;
        tiempoInicioEtapa = millis();
      }
      break;

    case ACCESO: // 10.0 segundos de paso peatonal
      if (transcurrido >= 10000) {
        digitalWrite(PIN_Q03, LOW);  // Bloquear Cerradura
        digitalWrite(PIN_Q04, HIGH); // Luz Roja
        etapaActual = IDLE;
      }
      break;
  }
}

void apagarActuadores() {
  digitalWrite(PIN_Q00, LOW); digitalWrite(PIN_Q01, LOW);
  digitalWrite(PIN_Q02, LOW); digitalWrite(PIN_Q03, LOW);
  digitalWrite(PIN_Q05, LOW);
}
